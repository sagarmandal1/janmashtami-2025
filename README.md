# শুভ জন্মাষ্টমী ২০২৫ | Happy Janmashtami 2025 

একটি সুন্দর এবং আকর্ষণীয় PHP ওয়েবসাইট যা জন্মাষ্টমী ২০২৫ উপলক্ষে তৈরি করা হয়েছে।

A beautiful and attractive PHP website created for Janmashtami 2025 celebration.

## 🕉️ প্রজেক্ট বিবরণ | Project Description

এই ওয়েবসাইটটি শ্রী কৃষ্ণের পবিত্র জন্মদিন জন্মাষ্টমী ২০২৫ উপলক্ষে তৈরি করা হয়েছে। এতে রয়েছে ঐতিহ্যবাহী নীল, হলুদ ও সোনালী রঙের থিম, বাংলা ও ইংরেজি উভয় ভাষায় কন্টেন্ট, এবং আধুনিক ওয়েব প্রযুক্তির ব্যবহার।

This website is created to celebrate Janmashtami 2025, the sacred birthday of Lord Krishna. It features traditional blue, yellow, and golden color themes, content in both Bengali and English, and modern web technologies.

## ✨ ফিচারসমূহ | Features

### 🎨 ডিজাইন | Design
- **Responsive Design**: Mobile-first approach with support for all screen sizes (320px to 1920px)
- **Color Theme**: Traditional blue (#1E3A8A), yellow (#FCD34D), and golden (#F59E0B) colors
- **Gradient Backgrounds**: Beautiful CSS3 gradients and animations
- **Typography**: Custom Bengali (Noto Sans Bengali) and English (Poppins) fonts
- **Animations**: Smooth transitions, particle effects, and interactive elements

### 📱 প্রযুক্তি | Technology
- **PHP 7.4+**: Server-side scripting with dynamic content
- **HTML5**: Semantic markup with SEO optimization
- **CSS3**: Grid, Flexbox, animations, and modern styling
- **JavaScript ES6+**: Interactive features and smooth scrolling
- **Font Awesome**: Beautiful icons and symbols

### 🌟 কন্টেন্ট | Content
- জন্মাষ্টমীর শুভেচ্ছা (Bengali and English greetings)
- কৃষ্ণের জন্ম কাহিনী (Birth story of Krishna)
- ঐতিহ্যবাহী আচার-অনুষ্ঠান (Traditional celebrations)
- পবিত্র শ্লোক ও বাণী (Sacred verses from Bhagavad Gita)
- মহামন্ত্র (Hare Krishna Maha Mantra)

## 🚀 সেটআপ নির্দেশনা | Setup Instructions

### 📋 প্রয়োজনীয় সফটওয়্যার | Requirements

- **PHP 7.4+** (বা তার উর্ধ্বে | or higher)
- **Web Server** (Apache, Nginx, or PHP built-in server)
- **Modern Browser** (Chrome, Firefox, Safari, Edge)

### 💻 লোকাল সেটআপ | Local Setup

#### 1️⃣ XAMPP ব্যবহার করে | Using XAMPP

**Windows/Mac/Linux:**

1. **XAMPP ডাউনলোড করুন | Download XAMPP:**
   ```
   https://www.apachefriends.org/download.html
   ```

2. **প্রজেক্ট কপি করুন | Copy Project:**
   ```bash
   # XAMPP htdocs folder-এ প্রজেক্ট কপি করুন
   # Copy project to XAMPP htdocs folder
   C:\xampp\htdocs\janmashtami-2025\  (Windows)
   /Applications/XAMPP/htdocs/janmashtami-2025/  (Mac)
   /opt/lampp/htdocs/janmashtami-2025/  (Linux)
   ```

3. **XAMPP শুরু করুন | Start XAMPP:**
   - Apache service চালু করুন | Start Apache service
   - Browser-এ যান | Open in browser: `http://localhost/janmashtami-2025/`

#### 2️⃣ WAMP ব্যবহার করে | Using WAMP (Windows)

1. **WAMP ডাউনলোড করুন:**
   ```
   http://www.wampserver.com/en/
   ```

2. **প্রজেক্ট কপি করুন:**
   ```bash
   C:\wamp64\www\janmashtami-2025\
   ```

3. **Browser-এ খুলুন:**
   ```
   http://localhost/janmashtami-2025/
   ```

#### 3️⃣ PHP Built-in Server

**যেকোনো OS-এ | Any OS:**

```bash
# Terminal/Command Prompt-এ যান
# Go to terminal/command prompt

cd /path/to/janmashtami-2025/
php -S localhost:8000

# Browser-এ খুলুন | Open in browser:
# http://localhost:8000
```

#### 4️⃣ MAMP (Mac)

1. **MAMP ডাউনলোড করুন:**
   ```
   https://www.mamp.info/en/downloads/
   ```

2. **প্রজেক্ট কপি করুন:**
   ```bash
   /Applications/MAMP/htdocs/janmashtami-2025/
   ```

## 🐛 সমস্যা সমাধান | Troubleshooting

### সাধারণ সমস্যা | Common Issues

1. **CSS/JS লোড হচ্ছে না | CSS/JS not loading:**
   ```
   ✅ Check file paths in index.php
   ✅ Verify server is running
   ✅ Check browser console for errors
   ```

2. **Bengali ফন্ট দেখাচ্ছে না | Bengali fonts not showing:**
   ```
   ✅ Check internet connection (Google Fonts)
   ✅ Clear browser cache
   ✅ Try different browser
   ```

3. **PHP errors:**
   ```bash
   # Error display চালু করুন | Enable error display
   ini_set('display_errors', 1);
   error_reporting(E_ALL);
   ```
