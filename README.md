# শুভ জন্মাষ্টমী ২০২৫ | Happy Janmashtami 2025

একটি সুন্দর এবং আধুনিক PHP ওয়েবসাইট যা ২০২৫ সালের জন্মাষ্টমী উৎসব উদযাপনের জন্য তৈরি করা হয়েছে। এই ওয়েবসাইটে ঐতিহ্যবাহী নীল, হলুদ ও সোনালী রঙের থিম ব্যবহার করা হয়েছে এবং বাংলা ও ইংরেজি উভয় ভাষায় কন্টেন্ট রয়েছে।

*A beautiful and modern PHP website created to celebrate Janmashtami 2025. This website uses traditional blue, yellow and golden color themes with content in both Bengali and English.*

## 🎉 ফিচারসমূহ | Features

### 🕉️ প্রধান বৈশিষ্ট্য | Main Features
- **দ্বিভাষিক সাপোর্ট** - বাংলা ও ইংরেজি উভয় ভাষায় সম্পূর্ণ কন্টেন্ট
- **রেসপনসিভ ডিজাইন** - সকল ডিভাইসে (মোবাইল, ট্যাবলেট, ডেস্কটপ) নিখুঁতভাবে কাজ করে
- **ঐতিহ্যবাহী থিম** - নীল (#1E3A8A), হলুদ (#FCD34D) ও সোনালী (#F59E0B) রঙের সংমিশ্রণ
- **ইন্টারঅ্যাক্টিভ অ্যানিমেশন** - মসৃণ স্ক্রলিং ও ফেড-ইন এফেক্ট
- **ডায়নামিক সময়** - রিয়েল টাইমে বাংলা ও ইংরেজিতে তারিখ ও সময় প্রদর্শন

*- **Bilingual Support** - Complete content in both Bengali and English*
*- **Responsive Design** - Works perfectly on all devices (mobile, tablet, desktop)*
*- **Traditional Theme** - Combination of blue, yellow and golden colors*
*- **Interactive Animations** - Smooth scrolling and fade-in effects*
*- **Dynamic Time** - Real-time date and time display in Bengali and English*

### 📱 প্রযুক্তিগত বৈশিষ্ট্য | Technical Features
- **PHP 7.4+** সাপোর্ট
- **HTML5** সেমান্টিক মার্কআপ
- **CSS3** গ্রিড ও ফ্লেক্সবক্স
- **JavaScript ES6+** ফিচার
- **SEO অপটিমাইজড** মেটা ট্যাগ
- **পারফরম্যান্স অপটিমাইজড** - দ্রুত লোডিং
- **অ্যাক্সেসিবিলিটি ফ্রেন্ডলি** - স্ক্রিন রিডার সাপোর্ট

## 🚀 ইনস্টলেশন ও সেটআপ | Installation & Setup

### 📋 প্রয়োজনীয়তা | Requirements
- **PHP 7.4** বা তার উপরের ভার্সন
- **Web Server** (Apache, Nginx, বা PHP Built-in Server)
- আধুনিক ব্রাউজার (Chrome, Firefox, Safari, Edge)

*- **PHP 7.4** or higher*
*- **Web Server** (Apache, Nginx, or PHP Built-in Server)*
*- Modern browser (Chrome, Firefox, Safari, Edge)*

### ⚡ দ্রুত শুরু | Quick Start

#### 1️⃣ প্রজেক্ট ডাউনলোড | Download Project
```bash
git clone https://github.com/sagarmandal1/janmashtami-2025.git
cd janmashtami-2025
```

#### 2️⃣ PHP বিল্ট-ইন সার্ভার | PHP Built-in Server
```bash
# প্রজেক্ট ডিরেক্টরিতে যান | Go to project directory
cd janmashtami-2025

# সার্ভার চালু করুন | Start server
php -S localhost:8000

# ব্রাউজারে খুলুন | Open in browser
http://localhost:8000
```

### 🖥️ XAMPP সেটআপ | XAMPP Setup

#### 1️⃣ XAMPP ইনস্টল করুন | Install XAMPP
- [XAMPP ডাউনলোড](https://www.apachefriends.org/download.html) করুন
- ইনস্টল করুন এবং Apache চালু করুন

*Download XAMPP and install, then start Apache*

#### 2️⃣ প্রজেক্ট কপি করুন | Copy Project
```bash
# XAMPP এর htdocs ফোল্ডারে প্রজেক্ট কপি করুন
# Copy project to XAMPP's htdocs folder
cp -r janmashtami-2025 /opt/lampp/htdocs/  # Linux
# অথবা Windows এ | Or on Windows:
# C:\xampp\htdocs\janmashtami-2025
```

#### 3️⃣ ব্রাউজারে চালান | Run in Browser
```
http://localhost/janmashtami-2025/
```

### 🔧 WAMP সেটআপ | WAMP Setup

#### 1️⃣ WAMP ইনস্টল | Install WAMP
- [WampServer ডাউনলোড](https://www.wampserver.com/) করুন
- ইনস্টল করুন এবং সার্ভার চালু করুন

#### 2️⃣ প্রজেক্ট কপি | Copy Project

```bash
C:\wamp64\www\janmashtami-2025\
```

#### 3️⃣ অ্যাক্সেস করুন | Access
```
http://localhost/janmashtami-2025/
```

## 🎨 কাস্টমাইজেশন | Customization

### 🎨 রঙ পরিবর্তন | Color Changes
`components/config.php` ফাইলে রঙ পরিবর্তন করুন:

*Change colors in `components/config.php`*:

```php
$theme_colors = [
    'primary' => '#1E3A8A',      // প্রাথমিক নীল | Primary Blue
    'secondary' => '#FCD34D',    // গৌণ হলুদ | Secondary Yellow
    'accent' => '#F59E0B',       // অ্যাক্সেন্ট সোনালী | Accent Golden
    // আরো রঙ... | More colors...
];
```

### 📝 কন্টেন্ট পরিবর্তন | Content Changes
`components/config.php` এ শুভেচ্ছা বার্তা পরিবর্তন করুন:

*Change greeting messages in `components/config.php`*:

```php
$bengali_greetings = [
    'main' => 'আপনার শুভেচ্ছা বার্তা',
    'secondary' => 'আপনার দ্বিতীয় বার্তা',
    // ...
];
```

### 🖼️ ছবি যোগ করা | Adding Images
`assets/images/` ফোল্ডারে ছবি যোগ করুন এবং HTML এ রেফারেন্স করুন।

*Add images to `assets/images/` folder and reference in HTML.*

## 🐛 ট্রাবলশুটিং | Troubleshooting

### ❌ সাধারণ সমস্যা | Common Issues

#### সমস্যা: "500 Internal Server Error"
**সমাধান | Solution:**
```bash
# PHP এরর লগ চেক করুন | Check PHP error log
tail -f /var/log/apache2/error.log

# ফাইল পারমিশন চেক করুন | Check file permissions
chmod 755 /path/to/project
chmod 644 /path/to/project/*.php
```

#### সমস্যা: CSS/JS লোড হচ্ছে না | CSS/JS Not Loading
**সমাধান | Solution:**
```bash
# ফাইল পাথ চেক করুন | Check file paths
ls -la assets/css/style.css
ls -la assets/js/script.js

# ব্রাউজার ক্যাশ ক্লিয়ার করুন | Clear browser cache
Ctrl+F5 (Windows/Linux) বা Cmd+Shift+R (Mac)
```

#### সমস্যা: বাংলা ফন্ট দেখা যাচ্ছে না | Bengali Font Not Showing
**সমাধান | Solution:**
- ইন্টারনেট কানেকশন চেক করুন (Google Fonts লোডের জন্য)
- Browser cache ক্লিয়ার করুন

*Check internet connection (for Google Fonts) and clear browser cache*
